## 关键爬取要点

### 1. 技术方案

- **工具**: Playwright (Python)
- **浏览器**: Chromium (headless模式)
- **页面加载策略**: `domcontentloaded` (避免networkidle超时)
- **等待时间**: 8秒 (确保JavaScript渲染完成)

### 2. 反爬规避

- 使用真实User-Agent
- 模拟浏览器视口 (1920x1080)
- 添加随机延迟

### 3. 数据提取要点

#### 巨量引擎 (open.oceanengine.com)

- 表格使用 `data-level` 属性标识层级
- 树形结构通过 `qz-tree-table` class实现
- 层级关系示例: data → rows → metrics/dimensions
- **字段名常是裸文本节点**，后跟标注span（需排除）：
  - `qz-table-level` (层级缩进，内容为 `&nbsp;`)
  - `qz-tag-view qz-tag-type-abandon` ("废弃"标注)
  - `qz-tag-view qz-tag-type-*` (其他标注如"新增"等)
  - **无class的标记span**（如 `<span style="color: #2ea121;"><strong>new</strong></span>`），内容是 `new`/`废弃`/`新增` 等标记词
- **正确提取顺序**：① 先取裸文本节点中的纯英文字段名（需清理 `\xa0` 等特殊字符）→ ② 再从span中找(排除上述标注和标记词) → ③ 兜底取整cell文本去掉中文标注词
- ⚠️ 切勿只遍历span取第一个有效文本——会把"废弃"/"new"等标注误当字段名（真实字段名是裸文本节点，不在span里）
- ⚠️ 裸文本节点可能带 `\xa0`（不间断空格），需用 `cleanText()` 清理后再匹配字段名正则

**两种页面布局（通用脚本均已自动适配）**：

| 布局 | 特征 | 提取方式 |
|------|------|----------|
| ① 标准 table | 用 `<table><tr>` 渲染，行有 `data-level` | 遍历 `tr`，取 `td` |
| ② section 模拟表格 | 无 `<table>`，用 `<section class="row body" data-level="N">` 模拟行 | 遍历 `section.row.body`，字段名取 `.col_params_name`、类型取 `.col_param_type`、描述取 `.description` |

- 布局②常见于部分新版文档页（如"获取已授权账户"），标题用"应答字段"而非"应答参数"
- 通用脚本逻辑：优先按 table 解析；若页面无 table（或无有效数据行），自动切换 section 布局
- ⚠️ section 布局的页面可能把"请求参数/Header"和"应答字段"合并在同一组 section 行里。通用脚本会定位"应答/应答参数/应答字段"标题，**只提取该标题之后的行**，避免请求参数混入

#### 小红书开放平台 (ad-market.xiaohongshu.com)

- **返回参数由多个并列表格组成**，每个表格前有一个标题（`<P>` 或 `<H2>`/`<H3>`/`<H4>`/`<H5>`）表示所属父字段
- 第一个表格是顶层（`code`/`msg`/`success`/`data`/`request_id`）
- 后续表格按链式结构：`标题 → 表格 → 标题 → 表格...`
- 表格列: 字段 | 类型 | 说明 | 备注 (4列)；部分接口有 **指标分类** 列（5列），通用脚本会自动将其并入备注列（格式：`[指标分类] 备注`）
- **无 `data-level` 属性**，层级靠表格前的标题推断
- ⚠️ **文档标题可能写错**：如 `trade_amount_agg_list` 的子表格前标题误写为 `wallet_trade_agg_list`。通用脚本会检测这种情况（标题等于当前表格父字段本身），自动用当前表格的最后一个 struct/list 字段作为父字段
- ⚠️ **标题标签不统一**：部分页面用 `<P>`，部分用 `<H2>`/`<H3>`/`<H4>`/`<H5>`，通用脚本均已适配
- ⚠️ **停止条件**：遇到 `示例：`/`请求示例`/`响应示例` 标题或 `PRE` 代码块时停止收集
- 层级构建：用栈跟踪路径，标题在栈中查找对应字段，找到后压栈；找不到则在当前表格找 struct/list 字段兜底

#### 磁力引擎 (developers.e.kuaishou.com)

- 表格使用 `ant-table-row-level-{n}` class标识层级
- 字段名cell包含多个span，需要排除:
  - `ant-table-row-indent` (缩进)
  - `field-add` / `field-adjust` (新增/调试标识)
  - `field-` 前缀的其他标识
- 标识文字示例: "新"、"调" (单字，需排除)

#### 腾讯营销开放平台 (developers.e.qq.com)

- **层级标识**：通过 row 的 class + 图标 判断
  - 无 class = 顶层字段（如 `list`、`page_info`）
  - `dynamic-generate-tr isShown` = 一级子字段（如 `list` 的子字段）
  - `hidd isShown` = 二级子字段（如 `page_info` 的子字段）
  - **图标判断**：`<i class="icon mkt-icon-folded">` = 有子字段；`<i class="icon mkt-icon-tdn">` = 叶子节点
- **字段名提取**：直接从第一个 cell 提取，需去掉末尾的 `*`（必填标记）
- **表格列**：名称 | 类型 | 描述 (3列)
- **应答表格识别**：含 `list` 或 `page_info` 字段的表格
- ⚠️ **特殊情况**：如果当前字段是叶子节点（无子字段），且栈顶元素有子字段，则当前字段应该挂到栈顶元素下。例如：`effect_funds`（有子字段）→ `effect_date`（叶子节点，应该挂到 `effect_funds` 下）

### 4. 字段名提取逻辑 (关键!)

```python
# 正确的字段名提取方法
for span in all_spans:
    span_class = span.get('class', [])
    # 跳过标识标签
    if ('ant-table-row-indent' in span_class or
        'field-add' in span_class or
        'field-adjust' in span_class or
        'field-' in span_class):
        continue

    text = span.get_text(strip=True)
    # 只接受长度>1的文本或英文字段名
    if text and (len(text) > 1 or re.match(r'^[a-zA-Z0-9_]+$', text)):
        field = text
        break
```

### 5. 层级关系处理

```python
# 使用栈构建父参数路径
path_stack = []  # 存储 (level, field_name)

for item in raw_data:
    level = item['level']
    field = item['field']

    # 弹出所有层级 >= 当前层级的元素
    while path_stack and path_stack[-1][0] >= level:
        path_stack.pop()

    # 构建父参数: 用 - 连接路径栈中的所有参数名
    if path_stack:
        parent = '-'.join([item[1] for item in path_stack])
    else:
        parent = ''

    # 将当前参数压入栈
    path_stack.append((level, field))
```

### 7. 常见问题

| 问题 | 原因 | 解决方法 |
|------|------|----------|
| 字段名提取为"新"/"调" | 标识span被误提取 | 排除`field-add`/`field-adjust` class |
| 字段名提取为"废弃" | 字段名是裸文本节点，标注在`qz-tag-type-abandon` span里 | 优先取裸文本节点；排除`qz-tag`/`tag-view` class |
| 字段名提取为"new" | 字段名裸文本带`\xa0`未清理，导致第一步失败；无class的`<span style="color:..."><strong>new</strong></span>`被误取 | 裸文本节点先用`cleanText()`清理`\xa0`；span提取时排除`new`/`废弃`/`新增`等标记词 |
| 页面加载超时 | networkidle等待过久 | 改用domcontentloaded |
| 文件被占用 | Excel文件打开 | 通用脚本已自动改用带时间戳的备用文件名 |
| 层级关系错误 | data-level提取失败 | 检查row的class属性 |
| 小红书层级错乱 | 文档标题写错（如`trade_amount_agg_list`的子表格前标题误写为`wallet_trade_agg_list`） | 通用脚本检测"标题=当前表格父字段"的情况，自动用当前表格的最后一个struct/list字段作为父字段 |
| 腾讯营销层级错乱 | `effect_funds`（有子字段）和`effect_date`（叶子节点）都是`hidd isShown`，无法通过class区分 | 通过图标判断：`<i class="icon mkt-icon-folded">` = 有子字段；如果当前字段是叶子节点且栈顶元素有子字段，则挂到栈顶元素下 |

# -*- coding: utf-8 -*-
"""
[平台名]API文档 - [接口名] - 返回参数爬取
"""
import asyncio
from playwright.async_api import async_playwright
import pandas as pd
import os
import re

async def scrape_api():
    """爬取API文档的返回参数数据"""
    url = "[文档URL]"

    async with async_playwright() as p:
        browser = await p.chromium.launch(headless=True)
        context = await browser.new_context(
            user_agent='Mozilla/5.0 (Windows NT 10.0; Win64; x64) AppleWebKit/537.36 (KHTML, like Gecko) Chrome/120.0.0.0 Safari/537.36',
            viewport={'width': 1920, 'height': 1080},
        )

        page = await context.new_page()
        print("Visiting page...")

        # 使用domcontentloaded避免超时
        response = await page.goto(url, wait_until='domcontentloaded', timeout=60000)
        print(f"Page loaded, status: {response.status}")

        # 等待页面完全加载
        await page.wait_for_timeout(8000)

        # 提取所有表格数据
        all_tables = await page.evaluate('''() => {
            const results = [];
            const tables = document.querySelectorAll('table');

            for (let i = 0; i < tables.length; i++) {
                const table = tables[i];
                const rows = table.querySelectorAll('tr');
                const tableData = [];

                for (const row of rows) {
                    if (row.classList.contains('ant-table-measure-row')) continue;

                    const cells = row.querySelectorAll('th, td');
                    if (cells.length < 5) continue;

                    let level = 0;
                    const className = row.className || '';
                    const levelMatch = className.match(/ant-table-row-level-(\\d+)/);
                    if (levelMatch) {
                        level = parseInt(levelMatch[1]);
                    }

                    // 提取字段名 - 排除标识标签
                    const fieldCell = cells[0];
                    const allSpans = fieldCell.querySelectorAll('span');
                    let field = '';

                    for (const span of allSpans) {
                        const spanClass = span.className || '';
                        // 跳过indent、field-add、field-adjust等标识标签
                        if (spanClass.includes('ant-table-row-indent') ||
                            spanClass.includes('field-add') ||
                            spanClass.includes('field-adjust') ||
                            spanClass.includes('field-')) {
                            continue;
                        }

                        const text = span.textContent.trim();
                        // 只接受长度>1的文本或英文字段名
                        if (text && (text.length > 1 || /^[a-zA-Z0-9_]+$/.test(text))) {
                            field = text;
                            break;
                        }
                    }

                    // 备用方法
                    if (!field) {
                        const allText = fieldCell.textContent.trim();
                        field = allText.replace(/[\\u65b0\\u8c03]$/, '').trim();
                    }

                    const type_ = cells[1]?.textContent.trim() || '';
                    const example = cells[2]?.textContent.trim() || '';
                    const desc = cells[3]?.textContent.trim() || '';
                    const note = cells[4]?.textContent.trim() || '';

                    tableData.push({
                        level: level,
                        field: field,
                        type: type_,
                        example: example,
                        desc: desc,
                        note: note
                    });
                }

                results.push({
                    index: i,
                    rowCount: rows.length,
                    data: tableData
                });
            }

            return results;
        }''')

        await browser.close()
        return all_tables

# 运行爬取
tables = asyncio.run(scrape_api())

print(f"\nFound {len(tables)} tables")

# 找到返回参数表格
response_table = None
for t in tables:
    has_code = False
    has_message = False
    has_data = False

    for row_data in t['data']:
        if row_data['field'] == 'code':
            has_code = True
        if row_data['field'] == 'message':
            has_message = True
        if row_data['field'] == 'data':
            has_data = True

    if has_code and has_message and has_data:
        response_table = t
        print(f"\nFound response params table (index: {t['index']}), rows: {len(t['data'])}")
        break

if not response_table:
    print("Response table not found, using table with most rows")
    response_table = max(tables, key=lambda t: len(t['data']))

# 处理数据
result_rows = []
path_stack = []

for item in response_table['data']:
    level = item['level']
    field = item['field']
    field_type = item['type']
    example = item['example']
    desc = item['desc']
    note = item['note']

    if field == '字段' or not field:
        continue

    while path_stack and path_stack[-1][0] >= level:
        path_stack.pop()

    if path_stack:
        parent = '-'.join([item[1] for item in path_stack])
    else:
        parent = ''

    result_rows.append({
        '父参数': parent,
        '子参数': field,
        '类型': field_type,
        '示例': example,
        '描述': desc,
        '备注': note
    })

    path_stack.append((level, field))

# 创建DataFrame
df = pd.DataFrame(result_rows)

print(f"\n=== 爬取结果 ===")
print(f"总行数: {len(df)}")
print(f"列数: {len(df.columns)}")
print(f"列名: {list(df.columns)}")

# 检查是否还有单字字段
single_char = df[df['子参数'].str.len() == 1]['子参数'].unique()
if len(single_char) > 0:
    print(f"\n警告：发现单字字段（可能是标识被误提取）: {single_char}")

# 保存到Excel
output_dir = r"C:\Users\13715\数仓_营销域_接口文档\[平台名]"
os.makedirs(output_dir, exist_ok=True)
output_file = os.path.join(output_dir, "响应参数_[平台名]_[接口名]接口数据.xlsx")

df.to_excel(output_file, index=False, engine='openpyxl')

print(f"\n文件已保存: {output_file}")
print(f"总数据行数: {len(df)}")
